# 미션 요구사항 재검증 기록

검증일: **2026년 10월 19일**. 원본 「미션 - AI 도구 학습」 PDF 6쪽을 다시 읽고, 기능 요구사항이 있는 2~5쪽은 렌더링한 화면까지 대조했습니다. 소스 검사, 자동 테스트, 실제 브라우저 조작 결과를 구분해 기록합니다.

## 판정

필수 기능 요구사항 10개 그룹에 구현 누락은 발견되지 않았습니다. 디자인을 흰 종이·얇은 표 선·파란 잉크를 사용하는 플래너 콘셉트로 변경했습니다. 자기소개, 프로젝트 소개와 선정 목록, API·메뉴·폼·테마의 기능은 유지했습니다. 이후 플래너 그림과 영문 장식을 제거하고 섹션 표기를 한국어로 정리했습니다. 이 정리에서는 JavaScript를 변경하지 않았습니다.

| PDF 요구사항 그룹 | 확인 근거 | 결과 |
| --- | --- | --- |
| 1. 프로젝트 기본 구성 | `index.html`, `css/`, `js/`, `images/` 분리, 외부 파일 연결, VS Code Live Server 설정·추천 확장 파일 | 충족. 로컬 환경에 `ritwickdey.liveserver-5.7.10` 설치도 확인 |
| 2. 시맨틱 HTML | header/nav/main/section/footer, API 카드 article, 6개 섹션, 앵커, 프로필 이미지 alt, 폼 label | 소스·자동 검사와 브라우저 확인 |
| 3. CSS·반응형 | CSS 변수와 다크 변수, Flexbox 내비게이션, auto-fit/minmax Grid, 768/1024px 분기, hover/transition/box-shadow | 소스와 Chrome의 7개 화면 너비에서 확인 |
| 4. DOM·이벤트 | defer, const/let, querySelector/All, textContent/innerHTML, classList, click/submit/scroll/input, preventDefault | 소스·자동 검사 및 실제 조작 확인 |
| 5. 인터랙션 | 모바일 메뉴 active 토글, 앵커 이동, 맨 위 버튼, 헤더 배경, 테마 저장, Intersection Observer | 실제 조작 및 경계값 자동 테스트 통과 |
| 6. 폼 UX | 이름·이메일·메시지, 필수값과 형식 검증, 필드별 오류, 기본 제출 방지와 성공 안내 | Chrome에서 빈 값·잘못된 값·정상 값 제출 확인 |

| 8. 비동기 API | 본인 계정 fetch/async-await, try/catch, 로딩/성공/실패/빈 상태, 403 및 재시도 | 실제 GitHub 성공 응답 + Chrome의 모의 응답 화면 + 자동 테스트 |
| 9. 상태 → 렌더링 | 테마·API·폼·메뉴·필터 상태와 렌더 함수 | 요구된 최소 3개 이상의 흐름 확인, README에 설명 |
| 10. 배포·제출 | 기존 GitHub Pages 배포, README 설명·기술·URL·스크린샷 | 배포 주소에서 최종 확인. 스크린샷은 이번 디자인으로 갱신 |

PDF의 코드 제약도 확인했습니다. React/Vue/jQuery/Bootstrap/Tailwind와 기타 외부 UI 라이브러리를 사용하지 않습니다. `var`, 인라인 이벤트, 인라인 스타일이 없고, 순수 HTML/CSS/JavaScript와 로컬 SVG로 구성합니다.

항목별 구현 위치는 [요구사항 대응표](requirements.md)에 있습니다. 학습 목표의 “스스로 설명할 수 있다”는 부분은 구현 검사만으로 학습자의 이해를 판정할 수 없으며, [학습 교재](../study-guide/README.md)와 README의 설명을 바탕으로 직접 설명해 보는 과정이 필요합니다.

## 실제 브라우저 확인

장식 정리 후에도 자동 테스트 46개를 재실행해 모두 통과했습니다. Chrome에서 320·375·768·1024·1440px의 가로 넘침 없음, 실제 프로젝트 7개·Python 필터 3개, 폼 필수값 오류와 성공 안내, 다크 모드 새로고침 유지도 재확인했습니다. 제출용 데스크톱·모바일·다크 모드 캡처는 그림과 영문 장식을 제거한 버전입니다.

Chrome **155.0.8059.82**와 Codex 내장 브라우저를 사용했습니다. 로컬 주소는 `http://localhost:5500/`이며 Python 정적 서버로 제공했습니다. VS Code 확장 설치와 프로젝트 설정은 확인했으나, 이번 브라우저 검증을 Live Server로 실행했다고 기록하지 않습니다.

| 조건·조작 | 관찰 결과 |
| --- | --- |
| Chrome 너비 320·375·767·768·1023·1024·1440px | 모두 가로 넘침 없음 |
| 프로젝트 Grid | 320·375px 1열, 767·768·1023·1024px 2열, 1440px 3열 |
| 메뉴 경계 | 767px에서 햄버거 표시·메뉴 숨김, 768px부터 데스크톱 메뉴 표시·햄버거 숨김 |
| 실제 GitHub API | 선정한 실제 프로젝트 7개와 한 문장 소개 표시 |

헤더 59/60px, 맨 위 버튼 299/300px, Observer 0.19/0.2의 정확한 경계는 아래 자동 테스트로 검증했습니다. 브라우저 조작에서는 일반 스크롤 동작을 확인했으며, 모든 경계를 픽셀 단위로 직접 재현했다는 뜻은 아닙니다.

## API 네 가지 상태

아래 API 상태 캡처는 장식 정리 전 검증 기록이며, 상태 처리 코드는 그대로 유지했습니다. 정상 성공은 실제 GitHub API로 확인했습니다. 로딩·빈 목록·403 오류는 원격 계정을 바꾸거나 한도를 소진하지 않고 **별도의 임시 로컬 테스트 페이지**에서 fetch 응답만 대체했습니다. 이 페이지는 실제 `js/projects.js`, `js/config.js`, `css/style.css`를 그대로 불러옵니다. 모의 응답 코드는 제품 파일이나 배포에 포함하지 않았습니다.

## 자동 테스트

`node --test tests/*.test.mjs`로 **46개 전체 통과**했습니다.

| 파일 | 개수 | 검증 범위 |
| --- | --- | --- |
| `tests/main.test.mjs` | 5 | 스크롤 경계, 테마 저장·복원·우선순위와 저장 차단, Observer 임계값, 모션 줄이기 |
| `tests/projects.test.mjs` | 22 | 로딩, 페이지네이션, HTTP/네트워크/JSON 오류, 재시도, 빈 상태, 시간 초과, 필터·정렬, 선정 목록, HTML 이스케이프·URL 방어 |
| `tests/contact.test.mjs` | 14 | 필수값·형식·길이, 오류 포커스·ARIA, 입력 수정, 성공 안내, 값 보존, 메일 초안 |
| `tests/structure.test.mjs` | 5 | 시맨틱·ID, 금지 문법·의존성, JS 구문, alt·label, 에셋·반응형·테마·모션 |

자동 테스트는 Node VM의 DOM·네트워크 대역과 소스 검사를 사용합니다. 모든 브라우저·보조기술·운영체제 조합에 대한 보장은 아닙니다.

## 선택 기능과 검증 범위

언어별 필터와 시스템 테마 감지는 구현되어 있습니다. 타이핑 효과와 Formspree/EmailJS 실제 이메일 전송은 구현하지 않은 **선택 과제**입니다. 필수 폼 검증과 성공 안내는 구현·검증되었습니다.

시스템 테마 변경, 저장소 차단, 모션 줄이기, 시간 초과, 페이지네이션의 예외 조합은 자동 테스트에서 확인했습니다. 이번 실제 브라우저 검증에서 각각을 모두 재현하지는 않았습니다. 스크린리더 전체 탐색과 실제 이메일 앱 전송은 검증 대상에 포함하지 않았습니다.
