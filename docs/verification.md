# 검증 기록

검증일: **2026년 10월 19일**. 로컬 HTTP 서버 및 GitHub Pages에서 실제 페이지를 열고 CUA로 Codex 내장 브라우저를 조작했습니다. 이 기록은 실제 브라우저에서 직접 확인한 결과와 코드 모의 검증을 구분합니다.

요구사항의 전체 목록은 [요구사항 대응표](requirements.md), 실행법과 설계는 [README](../README.md)를 참고하세요.

## 실제 브라우저에서 확인한 결과

아래는 최초 구현의 기록입니다. 이후 프로젝트 소개와 선정 기능을 추가했으며, 최초의 저장소 8개 표시는 선정 기능 적용 전 결과입니다.

저장소 개수와 필터 개수는 이 시점의 실제 계정 데이터입니다. 이후 새 저장소를 만들거나 언어가 바뀌면 수치가 달라질 수 있습니다. 콘솔 0건은 위 세션의 결과이며 모든 환경에서 오류가 없다는 보장은 아닙니다.

가로 모바일 메뉴는 높이가 짧을 때 마지막 항목에 접근할 수 있도록 최대 높이와 내부 스크롤을 보완한 뒤 다시 확인했습니다.

## 자동 테스트 결과

프로젝트 소개와 선정 기능을 포함하여 Node 기본 테스트 러너에서 **46개 전체 통과**했습니다. 프로젝트 폴더에서 다음 명령으로 재실행합니다.

```bash
node --test tests/*.test.mjs
```

| 파일 | 개수 | 검증 범위 |
| --- | --- | --- |
| `tests/main.test.mjs` | 5 | 59/60px·299/300px 경계, 테마 복원·선택 저장·우선순위, 저장소 예외, Observer 교차 비율 0.2, 모션 줄이기 초기 상태 |
| `tests/projects.test.mjs` | 22 | 로딩·중복 요청 방지, 페이지네이션·중복 제거, HTTP 오류·재시도, 부분 실패, 빈 목록, 필터·정렬, XSS 문자열·위험 URL 방어, 시간 초과, 응답 오류, 외부·순환 다음 링크 차단, 계정 미설정, 소개 교체·선정 목록 기준 필터/개수·API 교집합·유효하지 않은 소개 제외 |
| `tests/contact.test.mjs` | 14 | 필수값·공백·이메일·길이 경계, blur·input 검증, 오류 포커스·ARIA, 성공 미전송 안내, 입력 보존, 메일 초안 인코딩·초기화, 잘못된 수신 이메일 |
| `tests/structure.test.mjs` | 5 | 시맨틱 구조·ID, 인라인 스타일·이벤트·외부 패키지 부재, JS 문법·변수 선언, 이미지 alt·폼 label, 에셋·반응형·테마·모션 규칙 |

동작 테스트는 Node VM의 DOM·네트워크 모의 환경을 사용하고, 구조 테스트는 소스를 검사합니다. 브라우저 렌더링, 스크린리더 전체 탐색, 실제 이메일 앱 전송은 자동 테스트 범위에 포함하지 않습니다. `contact.js`의 개별 문법 검사와 초기 모의 검증도 별도로 수행했으며, 최종 결과는 위 테스트 묶음을 기준으로 합니다.

## 아직 실제 브라우저에서 확인하지 않은 범위

아래는 **실제 브라우저에서의 추가 확인 범위**입니다. 스크롤 경계, 저장소 예외, API 오류·빈 목록·페이지네이션, 모션 줄이기의 분기 로직은 위 자동 테스트에서 확인했지만 브라우저 화면에서의 재현과 구분합니다.

| 항목 | 추가 확인 방법 |
| --- | --- |
| 스크롤 경계값 | 59/60px, 299/300px에서 헤더·맨 위 버튼 변화 확인 |
| 시스템 테마·저장소 예외 | 저장 키 삭제 후 OS 테마 변경, 잘못된 저장값과 저장 차단 환경 확인 |
| API 로딩 지속 | 느린 네트워크 또는 지연 응답에서 로딩 패널 확인 |
| API 오류·재시도 | 네트워크 단절, 403·404·429·서버 오류 응답 후 복구 확인 |
| API 빈 목록 | `[]` 응답을 모의하여 빈 상태 표시 확인 |
| API 파싱·시간 초과 | 잘못된 JSON과 15초 초과 응답을 모의하여 안내 확인 |
| API 페이지네이션 | 여러 페이지·중복 ID·잘못된 다음 링크 응답을 모의하여 확인 |
| 모션 줄이기 | `prefers-reduced-motion: reduce`에서 모든 콘텐츠와 이동 확인 |
| 키보드·스크린리더 전체 탐색 | 확인한 skip link와 Escape 외에 Tab·Shift+Tab으로 전체 순회, 상태 알림을 보조기술로 확인 |
| 독립 Chrome 앱 전체 검사 | 이번 실행의 Chrome 연결 기능을 사용할 수 없어 앱 직접 제어를 시도했으나 응답 제한 시간 내 완료되지 않음. 주요 화면 검증은 위 내장 브라우저에서 수행 |

일부 항목을 향후 모의 테스트로 확인하더라도 실제 브라우저에서 확인했다는 기록으로 바꾸지 않습니다. 테스트 환경과 방법을 함께 기재합니다.
